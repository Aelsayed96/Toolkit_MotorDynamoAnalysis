## Presentation
Toolkit_MotorDynamoAnalysis project provides a **user-friendly, unified, flexible Dynamometer Reader and analyzer for different Dynamometer : Magtrol dynamometer files ( .MDF ) and Chinese Dynamometer Files ( .xls ) file**.
- Extract ALl regions ( locked , noload , max t , max po and custom regions
- define rated region by output power or speed or Using Load Torque for fan curve Equation
- motor comparison
- production samples statitics
- all report can be exported as pdf or latex
