⚙ FILE READER CONFIGURATION Define column aliases and derived parameters for each file type ✓ Saved
How it works: Each parameter has a list of column name aliases — the parser searches file headers for any of these (case-insensitive substring match). You can add, edit or remove aliases per file type.
Derived parameters let you define a new column by equation (e.g. Torque * Speed * 2*PI/60) or by reading an additional column from the file. Available variables in equations: Speed, Torque, Pin, Pout, Eff, PF, It, Im, Ia.

⚗ DERIVED PARAMETERS — Equations & Extra Columns ▾
Each derived parameter is computed after interpolation and overrides a built-in channel if the name matches, or adds a new channel otherwise. Leave equation blank to read the value from a file column instead.
